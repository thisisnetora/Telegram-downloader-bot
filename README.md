# 🤖 Netora AI

ربات تلگرامی چت هوش مصنوعی و ساخت تصویر — با سیستم عضویت اجباری در چنل، معرفی دوستان (رفرال)، سقف مصرف روزانه و پنل مدیریت کامل داخل ربات.

## ✨ امکانات

**کاربران:**
- 💬 چت با هوش مصنوعی **Google Gemini** (با حافظه گفتگو)
- 🖼 ساخت تصویر رایگان با **Pollinations** (مدل flux) در ۳ قاب: مربع، افقی، عمودی
- 📢 عضویت اجباری در چنل قبل از استفاده
- 👥 سیستم معرفی: کاربر باید چند نفر رو با لینک اختصاصی دعوت کنه تا ربات براش فعال بشه (رفرال فقط بعد از عضویت دعوت‌شده در چنل شمرده میشه — ضدتقلب)
- 👤 صفحه «حساب من» با لینک دعوت، پیشرفت و مصرف روزانه
- 🏆 جدول برترین معرف‌ها
- 🆕 شروع گفتگوی جدید (پاک شدن حافظه)
- 📵 سقف روزانه چت و تصویر (قابل تنظیم)

**مدیریت (`/admin`):**
- 📊 آمار کامل (کاربران، فعال‌شده‌ها، چت/تصویر امروز و کل)
- 👤 مشاهده اطلاعات کاربر با آیدی
- 🏆 برترین معرف‌ها
- 📢 پیام همگانی (متن، عکس، ویدیو و...)
- ⚙️ تنظیم تعداد معرفی لازم، سقف چت و تصویر روزانه — بدون ری‌استارت
- 🔧 حالت تعمیرات با یک کلیک
- 🚫 بن و رفع بن کاربر
- 📥 بکاپ دیتابیس و 📤 ریستور (برای جابه‌جایی بین اکانت‌ها)
- 🤖 بکاپ خودکار روزانه
- 🎉 اعلان خودکار وقتی کاربری ربات رو فعال می‌کنه

## 🗂 ساختار پروژه

```
bot.py            نقطه شروع + زمان‌بند بکاپ خودکار
config.py         تنظیمات از متغیرهای محیطی
database.py       دیتابیس SQLite (کاربران، رفرال، مصرف، تنظیمات)
utils.py          بررسی عضویت/دسترسی، بکاپ، ابزارها
keyboards.py      کیبوردها
services/ai.py    اتصال به Gemini و Pollinations
handlers/user.py  هندلرهای کاربر
handlers/admin.py پنل مدیریت
```

## 🚀 راه‌اندازی

### ۱. دریافت کلیدها
| چی | از کجا |
|---|---|
| `BOT_TOKEN` | ربات [@BotFather](https://t.me/BotFather) ← دستور `/newbot` |
| `GEMINI_API_KEY` | [Google AI Studio](https://aistudio.google.com/apikey) (رایگان) |
| `CHANNEL_ID` | یوزرنیم چنل مثل `@mychannel` — **ربات رو حتماً در چنل ادمین کن** |
| `ADMIN_IDS` | آیدی عددی خودت از [@userinfobot](https://t.me/userinfobot) |

### ۲. اجرای محلی
```bash
pip install -r requirements.txt
cp .env.example .env   # بعد مقادیر رو پر کن
python bot.py
```

### ۳. دپلوی روی Railway
1. پروژه رو روی GitHub push کن (بدون فایل `.env`)
2. Railway ← **New Project → Deploy from GitHub repo**
3. بخش **Variables** رو طبق جدول زیر پر کن
4. **خیلی مهم:** یک **Volume** بساز و به مسیر `/data` متصل کن، بعد متغیر `DB_PATH=/data/bot.db` رو ست کن — وگرنه با هر ری‌دیپلوی دیتابیس پاک میشه!

## ⚙️ متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `BOT_TOKEN` | — | توکن ربات (الزامی) |
| `GEMINI_API_KEY` | — | کلید Gemini (الزامی) |
| `GEMINI_MODEL` | `gemini-2.0-flash` | مدل Gemini |
| `CHANNEL_ID` | — | چنل عضویت اجباری (الزامی) |
| `CHANNEL_LINK` | از روی `CHANNEL_ID` | لینک چنل |
| `ADMIN_IDS` | — | آیدی ادمین‌ها، با کاما جدا کن |
| `BOT_NAME` | `Netora AI` | اسم ربات در پیام‌ها |
| `REQUIRED_REFERRALS` | `3` | تعداد معرفی لازم |
| `DAILY_CHAT_LIMIT` | `20` | سقف چت روزانه هر کاربر |
| `DAILY_IMAGE_LIMIT` | `3` | سقف تصویر روزانه هر کاربر |
| `DB_PATH` | `bot.db` | مسیر فایل دیتابیس (روی Railway: `/data/bot.db`) |
| `AUTO_BACKUP` | `true` | بکاپ خودکار روزانه برای ادمین |
| `BACKUP_HOUR` | `3` | ساعت بکاپ خودکار **به وقت سرور (UTC)** |

> 🕐 ساعت بکاپ به وقت UTC محاسبه میشه. مثلاً برای ۲:۳۰ بامداد به وقت تهران، `BACKUP_HOUR=23` بذار.

## 💾 بکاپ و انتقال بین اکانت‌ها

چون فایل بکاپ از طریق خود تلگرام جابه‌جا میشه، انتقال خیلی ساده‌ست:

1. **ربات قدیمی:** `/admin` ← 📥 بکاپ دیتابیس ← فایل توی چتت ذخیره میشه
2. **اکانت جدید Railway:** ریپو رو دپلوی کن + Volume جدید + متغیرها
3. **ربات جدید:** `/admin` ← 📤 ریستور بکاپ ← فایل رو بفرست ← تمام! ✅

با `AUTO_BACKUP=true` هر روز هم به‌صورت خودکار بکاپ برات ارسال میشه.
